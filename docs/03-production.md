# 03. 제작 워크플로우와 번아웃 방지

당신이 명시적으로 걱정한 것: **"지치고 즐거움을 잃을 것 같다."**
이건 의지 문제가 아니라 **설계 문제**다. 아래는 그 설계다.

---

## 1. 핵심 원리: 편당 제작 금지, 배치 제작

숏폼을 한 편씩 "기획→대본→녹음→편집→업로드" 하면 컨텍스트 전환 비용 때문에
편당 2~3시간이 든다. 같은 작업을 **묶어서** 하면 편당 40~60분으로 떨어진다.

### 주 1회, 3~4시간 사이클 (주 5편 생산)

| 블록 | 시간 | 하는 일 |
| --- | --- | --- |
| ① 소재 | 20분 | 소재 목록 파일(`content/ideas.md`, 아직 없음 — 만들 것)에서 5개 고르기. **여기서 새로 찾지 않는다** |
| ② 대본 | 70분 | 5편 연속으로 쓴다. 편당 14분. 타이머를 켠다 |
| ③ 팩트체크 | 25분 | 인용·수치·연도 확인. 확인 안 되면 삭제 (다시 쓰지 않음) |
| ④ 녹음 | 30분 | 5편 한 번에. 틀리면 그 문장만 다시. 처음부터 다시 금지 |
| ⑤ 편집 | 60분 | 첫 편에서 템플릿 완성 → 나머지 4편은 대본만 갈아끼움 |
| ⑥ 업로드 | 15분 | 5편 예약 발행. 제목/설명/태그도 템플릿 |

**소재 수집은 이 사이클 밖에서 한다.** 평소 책·기사·강의를 보다가 떠오르면
소재 목록 파일(`content/ideas.md`, 아직 없음 — 만들 것)에 한 줄만 던져 넣는다. 정리는 하지 않는다.
소재가 마르면 사이클이 무너지므로, **아이디어 재고를 항상 20개 이상** 유지한다.

---

## 2. 편집 템플릿을 자산으로 만들 것

1편을 잘 만드는 데 3시간을 쓰고, **그걸 템플릿으로 저장**한다. 고정할 것:

- 오프닝 0.5초 시그니처 (사운드 또는 로고 한 프레임)
- 자막 스타일: 폰트 / 크기 / 위치 / 색 / 강조색 **딱 하나**
- 화면 전환 방식 2개 (그 이상 쓰지 않는다)
- 배경음악 3트랙 (감동 / 사유 / 유쾌) — 이것만 돌려 쓴다
- 아웃트로 카드 (구독 유도, 1.5초)

이후 모든 편은 **텍스트와 자료만 교체**한다. 이게 "즐거움 유지"의 핵심이다 —
매번 디자인을 새로 고민하는 순간 제작은 노동이 된다.

## 3. 목소리와 자료

### 목소리: 본인 목소리로 간다
TTS가 빠르지만, 당신의 목표가 "아이덴티티를 담는 것"이라면 목소리를 포기하면 안 된다.
사람들이 결국 구독하는 것은 정보가 아니라 **말하는 방식**이다.
얼굴은 안 내도 된다 (faceless는 완전히 정상적인 전략). 목소리는 낸다.

- 마이크는 입문용 USB 콘덴서(5~15만 원대)로 충분하다. 스마트폰 이어폰 마이크도
  이불 씌운 조용한 방이면 생각보다 쓸 만하다.
- **감동 포맷은 톤을 낮추고 느리게.** 재미 포맷은 빠르게. 톤 차이가 시리즈를 구분한다.
- 녹음 전에 대본을 소리 내어 한 번 읽는다. 걸리는 문장은 무조건 다시 쓴다
  (읽기 어려운 문장 = 듣기 어려운 문장).

### 자료 화면 (저작권 안전 경로)
- **퍼블릭 도메인 명화**: 철학·인문 채널의 최고 자산이다.
  Wikimedia Commons, 각국 미술관 오픈 액세스 컬렉션(메트로폴리탄, 시카고 미술관 등)에서
  라이선스 표기를 확인하고 쓴다.
- **역사 사진**: 저작권 만료 여부를 개별 확인해야 한다. "구글에서 나왔으니 괜찮다"는 없다.
- **음악**: YouTube 오디오 라이브러리 또는 유료 구독형 라이브러리를 쓴다.
  유명 곡은 저작권 클레임으로 수익이 전부 넘어간다.
- **인용 텍스트**: 짧은 인용은 대체로 문제없지만, 번역문을 그대로 쓰면 **번역 저작권**이
  걸릴 수 있다. 직접 옮기거나 출처를 밝히고 짧게 쓴다.

라이선스 출처는 대본 파일 `## 출처`에 같이 적어둔다. 나중에 클레임이 오면 이게 방어 자료다.

## 4. 번아웃 방지 규칙 5개 (타협 금지)

### 규칙 1 — 주당 시간 상한을 정하고, 남기지 말고 넘기지도 말 것
예: **주 5시간.** 5시간이 되면 완성도가 80%여도 업로드한다.
숏폼은 80% 완성도로 5편이 20% 더 나은 3편보다 언제나 낫다.

### 규칙 2 — "완벽 금지" 선언
첫 20편은 **연습**이라고 못을 박는다. 20편 전까지 채널 디자인, 배너, 채널명 변경,
분석에 시간 쓰지 않는다. 20편이 없으면 분석할 데이터도 없다.

### 규칙 3 — 재고 버퍼 2주
예약 발행으로 **항상 2주 분량(8~10편)을 미리 쌓아둔다.**
이게 있으면 아픈 주, 바쁜 주, 의욕 없는 주에 채널이 멈추지 않는다.
버퍼가 없는 채널은 한 번의 슬럼프에서 죽는다.

### 규칙 4 — 조회수 확인은 주 1회, 정해진 시간에만
매시간 확인하는 습관이 즐거움을 가장 빠르게 파괴한다.
확인은 주간 사이클 시작 전 15분, 그때만. → `docs/04-metrics.md`

### 규칙 5 — 분기마다 '멋대로 만드는 1편'
조회수·알고리즘·포맷 전부 무시하고 만들고 싶은 걸 만든다.
성과를 측정하지 않는다. 이 1편이 당신이 왜 시작했는지를 기억하게 해준다.

## 5. 업로드 운영 기본값

- **발행 주기**: 주 4~5편, 요일 고정 (예: 화·수·목·금·토)
- **시간대**: 한국 타깃이면 저녁 7~10시 사이. 정하고 나서 6주간 바꾸지 않는다
- **제목**: 훅 문장을 그대로 쓴다. 낚시성 과장 금지 (지식 채널의 신뢰가 자산이다)
- **해시태그**: `#철학 #인문학` 같은 대분류 2~3개 + 인물/개념 1개
- **설명란**: 1줄 요약 + 출처 + 재생목록 링크. 템플릿화
- **재생목록**: 포맷 A/B/C 각각 하나씩. 롱폼용 하나. 총 4개로 시작
- **댓글**: 첫 30편은 **모든 댓글에 답한다.** 이게 초기 성장에 가장 저평가된 레버다
