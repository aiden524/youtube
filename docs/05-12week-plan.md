# 05. 12주 실행 계획

> **개정 필요.** 이 계획은 "숏폼 주 5편" 전제로 작성됐다.
> 최신 판단은 **미들폼(3~6분) 주 1편 + 숏폼 주 2~3편**이다
> (→ `docs/01-strategy.md` §0). 주당 투입 시간이 확정되면 전면 개정한다.

전제: **주당 투입 5시간 상한.** 그 이상 쓰지 않는다.
목표: 12주 후 "계속할지 / 무엇을 바꿀지"를 데이터로 판단할 수 있는 상태.

---

## 0주차 — 준비 (총 4시간, 이번 주만)

- [ ] 채널 생성. 채널명은 **개념어 + 감각어** 조합으로 (예: "○○의 밤", "생각의 ○○").
      완벽한 이름을 찾느라 시간 쓰지 않는다. 20편 뒤에 바꿀 수 있다
- [ ] 포맷 A / B / C 중 **시작할 3개 확정** (→ `docs/02-format.md`)
- [ ] 편집 템플릿 1개 완성 (자막 스타일, 오프닝 0.5초, BGM 3트랙)
- [ ] 소재 목록 파일(`content/ideas.md`, 아직 없음 — 만들 것)에 소재 **20개** 채우기
- [ ] 배너·프로필은 30분 안에 대충 만들고 끝낸다

**하지 말 것:** 채널 소개 문구 다듬기, 로고 외주, 장비 리서치, 경쟁 채널 100개 분석.

---

## 1~2주차 — 첫 10편 (연습)

- [ ] 주 5편 × 2주 = 10편. 요일·시간 고정 발행
- [ ] 배분: 포맷 A 4편 / C 4편 / B 2편
- [ ] **분석 금지.** 조회수를 보지 않는다. 목표는 오직 "10편 만들어냈다"
- [ ] 모든 댓글에 답한다
- [ ] 3편째쯤 대본 쓰는 속도가 눈에 띄게 붙는다. 이때 편당 시간을 기록해둔다

> 이 2주의 유일한 성공 조건: **10편이 올라가 있다.** 품질 기준은 없다.

---

## 3~4주차 — 훅 집중 개선

- [ ] 주 5편 유지 (누적 20편)
- [ ] 1~2주차 10편의 **평균 시청 지속률만** 확인. 다른 지표는 보지 않는다
- [ ] 60% 미만인 영상들의 첫 문장을 모아 놓고 무엇이 달랐는지 본다
- [ ] 이번 2주의 개선 항목은 **훅 하나만.** 훅 패턴 10개 중 잘 먹힌 3개에 집중
- [ ] 4주차 끝: 예약 발행 버퍼 **1주 분량** 확보 시작

---

## 5~6주차 — 아이덴티티 신호 읽기 + 롱폼 준비

- [ ] 주 5편 유지 (누적 30편)
- [ ] **처음으로 조회수당 구독 전환율을 본다.** 상위 5편을 뽑는다
- [ ] 연결형 댓글이 나온 영상을 표시한다 (→ `docs/04-metrics.md`)
- [ ] 그중 **당신이 아직 하고 싶은 말이 남은 것 1개**를 롱폼 소재로 확정
- [ ] 6주차에 롱폼 대본을 쓴다 (숏폼 시간 외 +3시간 예외 허용)
- [ ] 버퍼 2주 분량 확보

**롱폼 대본 구조 (8~12분):**
```
0:00-0:40  훅 — 숏폼과 다른 각도로 다시 던진다
0:40-2:00  왜 이 질문이 나를 붙잡았는지 (여기가 아이덴티티다. 생략하면 안 된다)
2:00-7:00  본론 — 개념 2~3개. 사례. 반론도 넣는다
7:00-9:00  전환 — 내가 처음에 틀렸던 것
9:00-10:00 여운 — 답을 주지 않고 닫는다
```
숏폼과 결정적으로 다른 부분은 **"내가 틀렸던 것"**이다.
정보는 어디서나 얻지만, 망설임과 수정은 당신에게서만 얻는다.

---

## 7주차 — 첫 롱폼 발행 (분기점)

- [ ] 숏폼 3편으로 줄인다 (롱폼에 시간 배분)
- [ ] **롱폼 1편 발행**
- [ ] 그 주 숏폼 3편은 롱폼과 같은 주제로 만든다 (예고 · 발췌 · 다른 각도)
- [ ] 롱폼 링크를 숏폼 고정 댓글에 단다
- [ ] 롱폼 발행 후 14일간 지표를 건드리지 않는다

---

## 8~11주차 — 리듬 정착

- [ ] 주 4~5편 숏폼 + 월 1편 롱폼 (10주차에 롱폼 2편째)
- [ ] **70:30 규칙 본격 적용.** 코어 30%를 명시적으로 태깅해서 만든다
- [ ] 잘 되는 포맷 하나를 시리즈화한다 (제목에 번호 붙이기, 재생목록 정리)
- [ ] 안 되는 포맷 하나를 버린다. **미련 갖지 않는다**
- [ ] 모든 대본에 `사후 기록`을 채운다 — 12주차 판단의 근거다

---

## 12주차 — 게이트 1 판정

- [ ] 숏폼 발행 편수 / 평균 시청 지속률 / 전환율 상위 5편 / 연결형 댓글 편수 집계
- [ ] `docs/04-metrics.md`의 게이트 1 체크리스트 판정
- [ ] 다음 12주 계획을 3줄로 쓴다

### 12주 후 현실적인 기대치
- 숏폼 50~55편, 롱폼 2편
- 구독자: **수백 ~ 수천 명.** 한 편이 터지면 1만도 가능하지만 그건 계획이 아니라 운이다
- 수익: 거의 0. 정상이다. 12주는 수익 구간이 아니다
- **얻는 것:** 대본 쓰는 속도, 통하는 훅 3개, 내가 지속 가능한 톤,
  그리고 "무엇에 대해 롱폼을 만들어야 하는지"에 대한 데이터

12주차에 구독자가 300명이어도 **위 4개를 얻었다면 성공이다.**
이건 자기 위로가 아니라, 롱폼 채널을 만들기 위한 필수 자본이다.

---

## 붙임: 이번 주에 할 일 (지금 당장)

1. 소재 목록 파일(`content/ideas.md`, 아직 없음 — 만들 것)에 소재 20개 — 오늘 60분
2. 포맷 3개 확정 — 15분
3. `docs/02-format.md`의 스크립트 템플릿으로 첫 5편 쓰기 — 90분
4. 채널 생성 + 편집 템플릿 1개 — 90분

**0주차의 성공 조건은 "1편 업로드"다.** 그 이상은 다음 주 몫이다.
