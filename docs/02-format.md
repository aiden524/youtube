# 02. 포맷 설계와 스크립트 템플릿

## 1. 숏폼의 물리 법칙

- **0~2초**: 스와이프 여부가 결정된다. 여기서 이탈률의 절반이 나온다.
- **2~10초**: "이 영상이 나에게 무엇을 약속하는가"가 서야 한다.
- **~45초**: 대부분의 지식 숏폼의 최적 길이. 30~50초를 기본값으로 잡는다.
- **마지막 2초**: 여운 또는 반전. 여기가 좋으면 좋아요/댓글/구독이 나온다.
- **말 속도**: 분당 320~400자 (한국어). 45초면 **240~300자**가 대본 분량이다.
  이 이상 쓰면 무조건 잘라야 한다.

> 대본을 쓸 때 글자 수를 먼저 정하고 시작하라. 이게 가장 큰 시간 절약이다.

---

## 2. 코어 구조: 4비트

거의 모든 지식 숏폼은 이 4개로 환원된다.

```
[훅]    2초 이내. 질문 · 단언 · 이상한 사실
[전개]  15~25초. 상황 하나만. 인물 하나만. 개념 하나만
[전환]  5~8초. "그런데" — 여기서 방향이 꺾인다
[여운]  3~5초. 질문으로 닫는다. 요약하지 않는다
```

**가장 흔한 실패:** 전개에 개념 3개를 넣는 것. 숏폼은 개념 **1개**다.
"이건 너무 단순한데?" 싶은 지점이 대체로 맞는 분량이다.

## 3. 훅 패턴 10개 (골라 쓰는 카드)

| # | 패턴 | 예시 |
| --- | --- | --- |
| 1 | 반대 단언 | "행복을 목표로 삼으면 절대 행복해지지 않습니다." |
| 2 | 2인칭 지목 | "당신이 어제 내린 결정, 사실 당신이 한 게 아닙니다." |
| 3 | 숫자 이상함 | "이 철학자는 평생 같은 시간에 산책했습니다. 딱 한 번 어겼어요." |
| 4 | 장면 던지기 | "1889년, 한 남자가 길에서 말을 껴안고 울었습니다." |
| 5 | 딜레마 | "친구가 300만 원을 빌려달라고 합니다. 갚을 능력은 없어요." |
| 6 | 상식 부정 | "가격이 오르면 수요가 줄어든다 — 이게 안 통하는 시장이 있습니다." |
| 7 | 유언/마지막 말 | "그가 마지막으로 남긴 말은 단 네 글자였습니다." |

첫 문장이 곧 훅이다.

## 4. 시작 포맷 3개 (이것만 반복)

처음에는 **3개만** 고정한다. 시리즈 이름을 붙여 재생목록으로 관리한다.

### 포맷 A — "만약 ○○라면" (재미 · 적용형)
오늘의 생활 딜레마에 철학자/경제학자를 소환한다.
```
[훅]   현실 딜레마 한 줄
[전개] 인물의 원칙 하나를 이 상황에 적용
[전환] 그 원칙이 만드는 불편한 결과
[여운] "당신은 어느 쪽인가요?"
```
- 강점: 무한히 뽑을 수 있다. 댓글이 잘 붙는다 (사람들이 편을 든다).
- 예: 칸트 / 벤담 / 아리스토텔레스 / 스토아 / 게임이론

### 포맷 B — "마지막 장면" (감동 · 서사형)
인물의 죽음·마지막 편지·마지막 순간 하나만 그린다. 설명하지 않고 **묘사**한다.
```
[훅]   연도 + 장면 (설명 금지)
[전개] 그 사람이 무엇을 잃었는지
[전환] 그런데 그가 마지막에 한 것
[여운] 그 말/행동을 그대로 남기고 끝 — 해석하지 않는다
```
- 강점: 이게 당신의 롱폼 원본이다. 저장·공유가 잘 된다.
- 주의: **팩트 정확도가 생명.** 각색은 톤까지만, 사실은 건드리지 않는다.

### 포맷 C — "당신의 상식이 틀렸다" (재미 · 반직관형)
경제·행동경제학에 특히 잘 맞는다.
```
[훅]   모두가 믿는 상식을 그대로 말한다
[전개] 반례 하나 (구체적 사례·숫자)
[전환] 왜 그런지 메커니즘 한 줄
[여운] "그래서 ○○할 때 조심해야 합니다"
```
- 강점: 저장률이 높다. "유용함"이 알고리즘에 잘 먹힌다.
- 주의: 재현 실패한 심리학 연구를 인용하지 않을 것 (→ `01-strategy.md` 함정 ③).

**포맷별 배분 (주 5편 기준):** A 2편 · C 2편 · B 1편.
B는 제작 시간이 가장 길고 조회수는 가장 불안정하지만, **당신이 남는 곳**이다.

## 5. 스크립트 파일 템플릿

스크립트는 `content/scripts/NNN-제목.md` 형식으로 저장한다 (디렉터리는 첫 대본을 쓸 때 만든다). 프론트매터를 반드시 채운다.

```markdown
---
번호: 007
제목: 시지프는 행복하다
포맷: B (마지막 장면)
도메인: 철학
톤: 감동
분류: 코어        # 코어 | 실험
길이: 42초
글자수: 268
공개일:
---

## 훅 (0-2초)
(한 문장)

## 전개 (2-25초)
(...)

## 전환 (25-33초)
(...)

## 여운 (33-42초)
(...)

## 화면 지시
- 0-2초: (자료 / 자막)
- ...

## 자막 (강조어만)
- ...

## 출처
- (1차 출처. 확인 안 된 인용은 삭제)

## 사후 기록  (업로드 7일 후 작성)
- 조회수:
- 평균 시청률:
- 조회수당 구독 (1,000회당):
- 댓글 성격:
- 배운 것 한 줄:
```

`사후 기록` 섹션이 이 채널의 진짜 자산이다. 60편이 쌓이면
"내가 어떤 걸 만들 때 사람이 남는지"에 대한 데이터베이스가 된다.

## 6. 롱폼으로 승격하는 규칙

숏폼 하나가 아래를 만족하면 **롱폼 후보**로 표시한다.

- 조회수당 구독 전환율이 채널 평균의 **2배 이상**
- 또는 댓글에 "더 알고 싶다 / 이거 길게 보고 싶다 / 생각하게 된다"류가 3개 이상
- 또는 당신이 다시 봐도 **아직 하고 싶은 말이 남아 있다** ← 이게 가장 중요하다

롱폼은 숏폼의 확장이 아니라 **숏폼이 못 담은 것**이다.
숏폼이 "결론"을 줬다면, 롱폼은 그 결론에 도달하는 **과정과 망설임**을 준다.
그 망설임이 당신의 아이덴티티다.
